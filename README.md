# ZECFUND
Creator fees go straight into Zcash

ZECFUND is a token built around one simple idea:

creator fees are used to accumulate Zcash.

## How it works

1. Creator fees are generated
2. Fees are sent to the treasury
3. Treasury uses the fees to acquire ZEC
4. Treasury activity is publicly verifiable
